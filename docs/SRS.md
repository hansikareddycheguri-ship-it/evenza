# Lumora

**Tagline:** *Discover Moments. Create Memories.*

## 1. Project Overview

Lumora is a full-stack event booking platform that enables users to discover events, book tickets, and manage their bookings through a simple and modern web interface. It also provides administrators with tools to create, update, and manage events while monitoring bookings through a dedicated dashboard.

The project is built as a capstone project to demonstrate full-stack web development skills including authentication, database integration, REST APIs, and responsive frontend development.

---

# 2. Project Objectives

The objective of Lumora is to:

* Allow users to register and log in securely.
* Display upcoming events.
* Enable users to view event details.
* Allow ticket booking.
* Maintain booking history.
* Allow administrators to manage events.
* Provide booking analytics through dashboards.

---

# 3. Target Users

## User

A registered user can:

* Register an account
* Log in
* Browse available events
* Search and filter events
* View event details
* Book tickets
* View booking history
* Log out

---

## Administrator

An administrator can:

* Log in
* Add new events
* Edit existing events
* Delete events
* View all bookings
* View dashboard statistics
