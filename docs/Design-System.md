# UI Principles

- Use whitespace generously.
- Keep interfaces clean and uncluttered.
- Use gradients only for buttons and hero sections.
- Avoid heavy shadows.
- Prefer rounded corners over sharp edges.
- Maintain consistent spacing across all pages.
